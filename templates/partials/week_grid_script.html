{#- Fork: the week grid shared by the slot page (timeline_script.html) and the propose times page. Styles in week_grid_style.html. var grid = calrsWeekGrid(opts) fills `opts.mount` with the grid: opts.duration meeting length in minutes (blocks are this tall) opts.labels { grid: aria label of the days, hint: pill text or '' } opts.formatTime(min) label of a minute of the day opts.formatAxis(h) label of hour h on the axis (1..23) opts.slotHref(ds, min) href of an offered start (default '#') opts.slotLabel(ds,min) aria label of an offered start opts.snap(ds, t) the start under minute t: null (no preview), or { min, ok, label, hidden }. Default: the latest offered start whose meeting covers t. opts.onSelect(ds, min) a click, Enter or Space on an offered start opts.onRefuse(ds, min, snapped) a click where snap said ok: false opts.layers(col, day, grid) adds a page's layers to a day column opts.viewOnly starts show, but nothing can be chosen grid.render(model) draws a week (or one day): model.days [{ ds, weekday, dayNum, today, starts: [min], regions: [[from, to]] (default: each start + duration) }] model.zone the zone label of the axis ('GMT+1') model.guest optional { zone, title, hour(h) }: a second axis left of the first, in the guest's zone model.youTitle label over the host axis when there is a guest axis model.selected [{ ds, min, text }] blocks drawn as chosen model.empty text shown when no day has a start ('' for none) Minutes count from the day's midnight in the grid's zone; the page converts. calrsWeekGrid.navButton(label, dir, enabled, onClick) makes the header's arrows. -#}
